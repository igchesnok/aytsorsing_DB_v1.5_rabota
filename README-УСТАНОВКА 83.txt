ЧТО ИСПРАВЛЕНО (по обратной связи)
----------------------------------

1. КОЛОНКА «ЛУЧШЕЕ ПРЕДЛОЖЕНИЕ» — НАЗВАНИЕ ФИРМЫ ПИШЕТСЯ ВСЕГДА
   Проблема: при установленной галке «не допускается разбивать партию»
   в ячейке колонки писалось имя фирмы, а при СНЯТОЙ галке имя НЕ
   писалось — только стоимость и трудоёмкость.
   Теперь:
   • галка СНЯТА — пишется имя фирмы-победителя по позиции; если партия
     разделена между фирмами по мощности — имена через « + », например:
     1 365,95 н/ч · ООО "Металлист-Тольятти" + ООО "Техспецсварка";
   • галка УСТАНОВЛЕНА — как раньше, имя фирмы-победителя на всю партию;
   • подсказка при наведении не изменилась: разбивка по фирмам (шт., цена,
     н/ч) видна в тултипе ячейки.

2. СТАТУС ЗАПРОСА — ВСЕГДА ВИДЕН
   Проблема: блок «Статус запроса» лежал внутри сворачиваемого блока
   фильтров и скрывался вместе с ним.
   Теперь блок перенесён в ШАПКУ фильтров (строка «Фильтры ▲») и остаётся
   видимым при любом состоянии фильтров — сворачивание на статус больше
   не влияет. Длинный статус не ломает шапку (обрезается многоточием,
   полный текст — во всплывающей подсказке).
   Примечание: механизм общий — любой странице достаточно добавить
   атрибут data-filters-status своему статусному блоку внутри фильтров.
