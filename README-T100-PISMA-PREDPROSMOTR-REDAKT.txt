T100 — ПИСЬМО В ПРЕДПРОСМОТРЕ + РЕДАКТИРОВАНИЕ ТЕКСТА ПИСЬМА
«Запросы на КП» (btnEmailFirma) + «Заказы по договорам» (st1Send)
=====================================================================

ЧТО СДЕЛАНО
-----------
1) «ЗАПРОСЫ НА КОММЕРЧЕСКИЕ ПРЕДЛОЖЕНИЯ» — кнопка «📧 Отпр.»
   (btnEmailFirma), окно «📋 Предпросмотр документов перед отправкой
   контрагентам»: добавлена вкладка «✉ Письмо: <фирма>» — ПО АНАЛОГИИ
   с «Заказами по договорам» (st1Send, T98). Для КАЖДОЙ выбранной
   фирмы — своя вкладка с точным текстом её письма:
     - Кому (адреса фирмы чипами), Копии (igor.chesnokov@vaz.ru;
       Aleksandr.Tyurin@vaz.ru), тема, полный текст (с подписью),
       плашка вложений (заявка + обменная форма).

2) РЕДАКТИРОВАНИЕ ТЕКСТА ПИСЬМА — в ОБОИХ предпросмотрах:
   - «Предпросмотр документов перед отправкой контрагентам» (Запросы);
   - «✉ Отправка заказа на согласование — предпросмотр письма» (Заказы).
   В письме появилась кнопка «✏ Редактировать текст»: текст открывается
   в поле правки, «✔ Применить правку» возвращает режим просмотра
   (правка сразу видна в письме). Подсказка: «правки текста уйдут в
   письмо при подтверждении отправки».

3) ОТПРАВКА С ПРАВКОЙ:
   - Запросы: отредактированный текст передаётся в
     POST /api/email/send-firms (body) — письмо фирме уходит ИМЕННО
     в отредактированном виде (тема и копии — из конструктора);
     для отправки без правки ничего не менялось.
   - Заказы: отредактированный текст передаётся в
     POST /api/orders/send-email (body) — аналогично.

4) НОВЫЙ ENDPOINT: POST /api/email/firms-email-preview
   { zaprosId, url3D, firms: [{firmKod, firmName, email}] } ->
   { ok, previews: [{firmKod, firmName, to, cc, subject, body}] }.
   БЕЗ отправки и БЕЗ изменения данных. Использует ЕДИНЫЙ конструктор
   письма buildZaprosFirmaEmail с реальной отправкой (шаблон перенесён
   из POST_SEND_FIRMS байт-в-байт) — предпросмотр ВСЕГДА = то, что уйдёт.

5) ГАРАНТИЯ «ПРЕДПРОСМОТР = ОТПРАВКА»:
   - офлайн-тест 32/32: письмо из предпросмотра и письмо из реальной
     отправки совпадают побайтно (subject/body/cc);
   - правка не портит тему/копии — редактируется только текст.
