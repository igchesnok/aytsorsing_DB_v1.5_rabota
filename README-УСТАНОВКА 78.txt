======================================================================

ЧТО СДЕЛАНО
-----------
1. ТРЕБОВАНИЕ ЗАПРОСА «ВСЕ ПОЗИЦИИ ИЗГОТАВЛИВАЮТСЯ КОМПЛЕКТОМ»
   • В таблицу запросов КП (zapros_kp) добавлена колонка komplekt
     (миграция выполняется автоматически при запуске сервера).
   • На странице «Внесение КП» чекбокс «не допускается разбивать
     партию» устанавливается ИЗ ЭТОГО ПОЛЯ (а не из localStorage, как
     раньше) и ПРИ ПЕРЕКЛЮЧЕНИИ СОХРАНЯЕТСЯ В ЗАПРОС — требование
     хранится вместе с запросом и виден после перезахода (F5).

2. МАТРИЦА ВЫБОРА ПОСТАВЩИКА
   • Строки ОБЪЕДИНЕНЫ по № чертежа: синтетически разделённые позиции
     плана (разделение по мощности) показываются ОДНОЙ строкой,
     плановое количество СУММИРУЕТСЯ (подпись «N шт. · K поз. плана»).
   • КП одной фирмы на разделённых позициях (создано копированием)
     НЕ задваивается: по чертежу берётся одно предложение фирмы —
     лучшая цена за 1 деталь, при равенстве — меньшая трудоёмкость;
     мощность фирмы — максимальная заявленная.
   • Нумерация позиций (колонка «№») + чекбокс в строке — позиция
     показывается на диаграмме (вместо синхронизации кликом).
   • НОВАЯ КОЛОНКА «Лучшее предложение»: стоимость и трудоёмкость
     партии позиции ПО ПЛАНОВОМУ КОЛИЧЕСТВУ:
     - требование снято — партия распределяется по мощности фирм:
       лучшая фирма (цена за 1 деталь → трудоёмкость) — на свою
       мощность, остаток — следующей лучшей; в строке отмечаются ★
       ВСЕ фирмы-победительницы с их количеством («2 шт.»);
     - требование установлено — предложение фирмы-победителя на ВСЮ
       партию: и стоимость, и ТРУДОЁМКОСТЬ её (не сборная).
   • ИТОГО по плановому кол-ву (мощность фирмы может быть завышена —
     для адекватного сравнения берётся план):
     - «Целевая ПТО» — Σ только по позициям, у которых есть хотя бы
       одно предложение (позиции без предложений исключены, подпись
       «без N поз. без КП»);
     - «Лучшее предложение» — Σ одноимённой колонки;
     - ИТОГО ПО ФИРМАМ показывается ТОЛЬКО когда: (а) в запросе
       установлено «не допускается разбивать партию» И (б) у фирмы
       есть предложения по ВСЕМ позициям; сумма = Σ (цена за деталь ×
       плановое кол-во), под ней трудоёмкость партий; ★ — минимум.

3. ДИАГРАММА «СТОИМОСТЬ И ТРУДОЁМКОСТЬ ПАРТИИ» (вместо scatter t75/t76)
   • Координаты: X — трудоёмкость партии (н/ч), Y — стоимость партии
     (₽); все суммы по ПЛАНОВОМУ количеству.
   • ◆ ЦЕЛЬ — итоги колонки «Целевая ПТО» (позиции с одинаковым
     чертежом = одна позиция; позиции без предложений исключены).
   • ⭑ «ЛУЧШЕЕ ПРЕДЛОЖЕНИЕ» — итоги одноимённой колонки матрицы
     (при «комплекте» — фирма-победитель на всю партию).
   • Отмеченные чекбоксами позиции — символы с НОМЕРОМ позиции внутри;
     итоговые точки — без номера. Легенда: № — чертёж.
   • Диаграмма ИНТЕРАКТИВНАЯ: колесо — масштаб, перетаскивание —
     сдвиг, двойной клик или кнопка «⟲ Сброс» — исходный вид.
   • Селект режима удалён (заменён чекбоксами строк матрицы).
