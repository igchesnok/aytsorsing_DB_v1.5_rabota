ПРЕДПРОСМОТР ПЕЧАТИ ЗАКАЗА (st2Print)
=====================================================================

ЧТО СДЕЛАНО
-----------
1) ШАГ 1 «Отправка на согласование контрагенту» — кнопка «✉ ➜»
   Больше НЕ показывает стандартное confirm-окно «вслепую».
   Вместо него открывается окно предпросмотра письма:

     • вкладка «✉ Письмо» — письмо так, как увидит контрагент:
       - Кому: все адреса из комбобокса шага 1 (чипами);
       - Копии: igor.chesnokov@vaz.ru; Aleksandr.Tyurin@vaz.ru
         (те же копии, что уходят реально);
       - тема письма;
       - полный текст письма (с подписью);
       - плашка вложения «Заказ № … .xlsx»;
     • вкладка «📄 Вложение — Заказ № … .xlsx» — сам заказ
       (существующий Excel→HTML предпросмотр).

   Кнопки окна: «✅ Отправить письмо» / «✖ Отменить отправку»
   (Esc тоже отменяет). Отправка — ТОЛЬКО по явному подтверждению.
   Текст/адреса/копии берутся с сервера: новый endpoint
   POST /api/orders/email-preview использует ЕДИНЫЙ конструктор
   письма с реальной отправкой — предпросмотр всегда = то, что уйдёт.
   Если endpoint недоступен (сервер без T98) — автоматический
   запасной путь со старым confirm-окном.

2) Кнопка «🖨» (id="st2Print", шаг 2) — и такие же кнопки печати
   заказа в шапке (btnPrintExcel) и на шаге 3 (st4Print):
   сначала открывается ПРЕДПРОСМОТР заказа (Excel → HTML),
   скачивание — по подтверждению:
     • «⬇ Скачать Excel» — подтверждает и скачивает;
     • «⬇ Скачать XLSX» — ссылка мгновенного скачивания рядом с кнопками;
     • «✖ Отмена» / Esc — ничего не скачивается.

ИСПОЛЬЗОВАННЫЕ СУЩЕСТВУЮЩИЕ МЕХАНИЗМЫ
-------------------------------------
• Excel→HTML предпросмотр (generatePreviewHTML) — без изменений;
• общее окно предпросмотра showExcelPreview (вкладки, кнопки,
  ссылка скачивания — T59) — без изменений;
• POST /api/orders/send-email — без изменений (логика и текст письма
  те же, вынесены в общий конструктор buildOrderApprovalEmail).

---------
• Предпросмотр письма: кому/копии/тема/текст/вложение — на живых данных

  generate-excel и send-email;
