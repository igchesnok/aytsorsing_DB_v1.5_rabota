=========================================================================

Страница «Запросы на коммерческие предложения», шаг 2 «Ссылка от
технолога на черт. и 3D мод.» (поле «Ссылка», zUrl).

ЗАДАЧА
------
Технолог присылает ссылку на документацию (обычно публичная ссылка
Яндекс.Диска). Раньше о том, что по ссылке реально скачивается,
становилось известно только по жалобам контрагентов: например, в папке
«Заявка №11 2026» из трёх чертежей два НЕ скачиваются, а один
скачивается. Теперь ссылку можно проверить сразу.

ЧТО СДЕЛАНО
-----------
1. Кнопка «🔗 Проверить загрузку» под полем «Ссылка». Появляется,
   только когда ссылка заполнена; после изменения ссылки прежний
   отчёт скрывается.
2. По кнопке сервер:
   • проходит по ссылке (публичные ссылки Яндекс.Диска:
     disk.360.yandex.ru / disk.yandex.ru / yadi.sk);
   • получает перечень ВСЕХ файлов, включая вложенные папки
     (одиночная ссылка на файл/архив — тоже поддерживается);
   • ПРОБНО скачивает КАЖДЫЙ файл (Range-GET первых 2 байт с
     ожиданием первого байта передачи);
   • Сами файлы НИКУДА НЕ СОХРАНЯЮТСЯ — проверяется только факт
     возможности загрузить.
3. Отчёт под ссылкой:
   • сводка: «Заявка №11 2026» — файлов: 3 · загружаются: 1 ·
     НЕ грузятся: 2 (время проверки);
   • красный блок «❌ Не прогрузились (N)» с ИМЕНАМИ файлов и
     причиной каждого сбоя (сервер не ответил — таймаут; соединение
     оборвано до начала передачи; HTTP-код; вместо файла вернулась
     HTML-страница и т.п.);
   • полный список файлов: ✅ грузится / ❌ нет, размер каждого.
   Плюс всплывающее уведомление с итогом.
4. Проверка ничего не изменяет: ни базу, ни файлы, ни письма.

УСТАНОВКА
---------
1. Остановить сервер.
2. Заменить файлы (сохранить структуру папок: src/..., public/...).
3. Запустить сервер (zaprosKpRoutes.js и router.js — СЕРВЕРНЫЕ,
   перезапуск ОБЯЗАТЕЛЕН).
4. На странице обновить кэш браузера (Ctrl+F5).

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. «Запросы на коммерческие предложения» → выбрать запрос (шаг 2 должен
   быть виден — запрос уже отправлен технологу).
2. Вставить ссылку в поле «Ссылка» → появится кнопка «🔗 Проверить
   загрузку» → нажать.
3. Под ссылкой появится отчёт: сколько файлов загружается, сколько нет,
   имена непрогрузившихся и причина по каждому. Ссылку можно
   перезапросить у технолога, не дожидаясь жалоб контрагентов.
4. Изменили ссылку — отчёт скрывается; проверьте новую ссылку той же
   кнопкой.
