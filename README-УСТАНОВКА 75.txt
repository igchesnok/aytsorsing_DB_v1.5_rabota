ЧТО ДЕЛАЕТ
----------
Второй график под матрицей выбора (t74): «Трудоёмкость и стоимость
по фирмам» — SVG-диаграмма рассеяния, БЕЗ внешних библиотек.

  • ТОЧКА = фирма, давшая хотя бы одно предложение с ценой
    (тот же набор, что в матрице выбора; фирмы без предложений
    не отображаются);
  • X — суммарная трудоёмкость партий (Σ трудоёмкость ед. × кол-во,
    н/ч); Y — суммарная стоимость партий (Σ стоимость ед. × кол-во,
    руб. без НДС);
  • НИЖЕ И ЛЕВЕЕ — ВЫГОДНЕЕ (меньше трудоёмкость и дешевле);
    подсказка на поле диаграммы;
  • ◆ ЦЕЛЬ — точка целевых параметров запроса (Σ труд-ть ПТО ×
    план кол-во; Σ целевая стоимость ПТО); пунктирные линии —
    уровни цели по осям; диагональ из начала координат через Цель —
    геометрическое место точек со СРЕДНЕЙ ЦЕНОЙ н/ч, РАВНОЙ ЦЕЛЕВОЙ
    (выше диагонали — фирма запрашивает цену н/ч выше целевой,
    ниже — ниже целевой);
  • контурная (пунктирная) точка — фирма предложила цену НЕ по всем
    позициям: её суммы несопоставимы с полными (та же честная логика,
    что у ★ ИТОГО матрицы выбора); в легенде — чипы в том же стиле;
  • НАВЕДЕНИЕ на точку/ромб — тултип: стоимость партий, трудоёмкость
    партий, средняя цена н/ч, покрытие «N из M поз.», отклонение от
    целевой (₽ и %), предупреждение о неполном покрытии;
  • КЛИК по точке — выбрать фирму в фильтре сводной (группа фирмы
    центрируется, как при клике по ИТОГО матрицы);
  • сетка и подписи осей автоматически «красивые» (шаг 1/2/5×10^k,
    компактные числа: 4,6 млн); при изменении ширины окна диаграмма
    перестраивается;
  • подписи фирм возле точек не пересекаются (перебор позиций).

Scatter рендерится ВМЕСТЕ с матрицей выбора из ТЕХ ЖЕ данных
(Offers._allKP, без запросов к серверу): смена запроса, фильтр
«Без КП», сохранение КП, импорт из Excel — всё отражается сразу.
Нет данных/нет предложений — блок скрывается сам.

УСТАНОВКА
---------
1. Файлы клиентские — останавливать сервер не нужно.
2. Скопируйте 2 файла из архива в папку проекта ПОВЕРХ существующих.
3. В браузере: Ctrl+F5 (кэш модулей!).
4. Откройте «Внесение коммерческих предложений», выберите запрос КП
   с предложениями — под матрицей выбора появится диаграмма.
