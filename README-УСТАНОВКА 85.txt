t85 — МАРШРУТ ДОЧЕРНИХ ПОЗИЦИЙ ПЛАНА (РАЗДЕЛЕНИЕ ПО МОЩНОСТИ)
==============================================================

БАГ (ваш случай)
----------------
Позиция PPG_20261017055955_70128 (чертёж 85104107014031 «CTOЙKA»,
ООО «Техспецсварка», 4 шт.) появилась после разделения основной позиции
из-за недостаточности мощности (Запрос №4). Она создалась БЕЗ маршрута
движения (шагов перевозки): механизм разделения копировал все поля
позиции плана, но НЕ копировал шаги маршрута (shagi_marshruta) родителя.

Что происходило: без шагов маршрута система не знает, какой этап
перевозки у позиции «текущий» — поэтому позиция НЕ попадала в таблицу
«Доступные позиции для добавления» на странице «План перевозок»
(«нападает» = «не попадает»). Не добавив её в план перевозок, нельзя
создать и грузовые позиции (грузовые привязываются к строкам плана
перевозок).

У родительской позиции PPG_20260915174013_39104 маршрут был (создан
массовым «Заполнить маршруты» 25.09.2026), поэтому она добавлялась
без проблем.

ЧТО СДЕЛАНО
-----------

1. РАЗДЕЛЕНИЕ БОЛЬШЕ НЕ ТЕРЯЕТ МАРШРУТ (zaprosKpRoutes.js)
   Новый хелпер copyPlanRoute копирует шаги и операции маршрута
   родителя на дочернюю позицию (новые id, связь как в «Копировать
   маршрут»). Вызов добавлен во ВСЕ 4 места создания дочерних позиций:
   • разделение по мощности (createChildPlan — «Частичные операции»);
   • маркер «нет КП» (когда КП нет вовсе);
   • позиция-остаток после распределения мощностей;
   • каскадный остаток (доназначение при отказе/исключении фирм).
   Повторно маршрут не дублируется (защита от повторного копирования).

2. АВТО-РЕМОНТ ПРИ СТАРТЕ СЕРВЕРА (Database.js)
   repairChildPlanRoutes(): при запуске сервера находит дочерние
   позиции (is_child_plan = 1) без единого шага маршрута, у которых
   маршрут есть у родителя, и восстанавливает его копированием.
   • Ваша позиция PPG_20261017055955_70128 починится АВТОМАТИЧЕСКИ
     при первом запуске сервера с этим обновлением — вручную базу
     править не нужно;
   • в лог сервера пишется: «🔧 T85: найдено дочерних позиций без
     маршрута: N — восстанавливаю из родителя»;
   • работает один раз: после ремонта повторных запусков нет.

ФАЙЛЫ (серверные — ПЕРЕЗАПУСК СЕРВЕРА ОБЯЗАТЕЛЕН)
-------------------------------------------------
src/routes/zaprosKpRoutes.js   — copyPlanRoute + 4 вызова
src/Database.js                — repairChildPlanRoutes() + вызов в connect()

УСТАНОВКА
---------
1. Остановить сервер.
2. Заменить файлы (сохранить структуру папок src/...).
3. Запустить сервер — ремонт выполнится автоматически (см. лог).
4. Открыть «План перевозок» → направление «Исходящая» → в списке
   «Доступные позиции для добавления» появится позиция
   85104107014031 / ООО «Техспецсварка» / 4 шт. → отметить →
   «Добавить выбранные». Дальше позиция доступна для грузовых позиций
   в транспортных операциях как обычно.
