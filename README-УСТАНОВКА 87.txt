t87 — ФИЛЬТР ПО ФИРМЕ ОБНОВЛЯЕТ СПИСОК ТРАНСПОРТНЫХ ОПЕРАЦИЙ
============================================================

ЗАДАЧА
------
На странице «Редактор транспортных операций» при выборе фирмы в
выпадающем списке #toFirma (блок фильтров над таблицей операций) список
транспортных операций НЕ обновлялся, хотя при выборе статуса (#fltStatus)
всё обновлялось корректно.

ПРИЧИНА
-------
Обработчик изменения #toFirma обновлял форму получателя
(onFirmaChange), доступные позиции и кнопки, но НЕ вызывал
TransportOps.applyFilters() — перезагрузку таблицы операций с фильтрами.
Вся цепочка фильтра по фирме при этом была готова с самого начала:
  • таблица transport_oper (FilterableTable) объявляет фильтр
    fltFirma -> dbField «id_firma»;
  • сервер (transportOps.list, buildWhere) фильтрует по toper.id_firma = ?;
  • applyFilters() уже читал значение #toFirma — просто никто не вызывал
    его при смене фирмы.

Попутно найден и устранён МЁРТВЫЙ КОД: в обработчике «Только фирмы с
доступным грузом»/фильтров года блок «если выбранная фирма исчезла —
сбрасываем» никогда не выполнялся: fillFirmaSelect() сам сбрасывает
исчезнувшую фирму ещё до проверки, а пустое значение всегда совпадает
с пунктом-заглушкой списка. Из-за этого при исчезновении фирмы формы
не очищались, а таблица оставалась отфильтрованной по сброшенному
фильтру.

ЧТО СДЕЛАНО (public/js/modules/transportOps.js — 3 правки)
----------------------------------------------------------
1. Обработчик change #toFirma: добавлен TransportOps.applyFilters() —
   смена фирмы (включая возврат к «— Выберите фирму —») перезагружает
   список операций под выбранный фильтр.
2. onHeaderClick() (сброс выбора кликом по шапке таблицы): очистка
   #toFirma происходит БЕЗ события change (через Receiver.clearForm()),
   поэтому добавлена синхронизация таблицы — фильтр и таблица всегда
   показывают одно и то же.
3. Обработчик chkFirmaWithCargo/годов договора: мёртвый блок заменён
   рабочим — фирма запоминается ДО перезагрузки списка; если после
   перезагрузки она исчезла (сброшена fillFirmaSelect), формы очищаются
   и таблица синхронизируется.

ФАЙЛЫ
-----
public/js/modules/transportOps.js — единственный изменённый файл
(КЛИЕНТСКИЙ: перезапуск сервера НЕ требуется).

УСТАНОВКА
---------
1. Заменить файл public/js/modules/transportOps.js.
2. На странице обновить кэш браузера (Ctrl+F5).
Перезапуск сервера не нужен, изменений на сервере нет.

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. «Редактор транспортных операций» → выберите фирму в списке над
   таблицей операций — список сразу покажет только операции этой фирмы.
2. «— Выберите фирму —» — снова все операции.
3. Фильтры работают совместно: фирма + статус + направление.
4. Выбор фирмы по-прежнему заполняет форму получателя (код, ИНН,
   адреса, контакты) — прежнее поведение сохранено.
