t84 — СПРАВОЧНИК ФИРМ: ПОЛЯ «ГОРОД» И «ЦЕНА ПЕРЕВОЗКИ»
=======================================================

ЧТО СДЕЛАНО
-----------

1. БАЗА ДАННЫХ — НОВЫЕ КОЛОНКИ ТАБЛИЦЫ ФИРМ (firmy)
   • gorod            — город фирмы (TEXT, по умолчанию пусто);
   • cena_perevozki   — цена перевозки (TEXT, по умолчанию пусто;
                        числа в проекте хранятся строкой — как
                        kp.cena_postavshika и др.).
   Миграция автоматическая: при первом запуске сервера колонки
   добавляются к существующей базе (данные не затрагиваются).

2. СТРАНИЦА «УПРАВЛЕНИЕ ФИРМАМИ»
   • Форма «Данные фирмы»: новые поля ввода «Город» и
     «Цена перевозки» (порядок: Код, Наименование, ИНН, Город,
     Юр. адрес, Цена перевозки);
   • Таблица фирм: колонки «Город» (после ИНН) и «Цена перевозки»
     (после Юр. адреса);
   • Выбор строки подставляет значения в форму, «Сохранить» пишет их
     в БД, создание фирмы — сохраняет сразу; после F5 всё
     восстанавливается.

3. API
   • POST /api/firmy — создание с gorod и cena_perevozki;
   • PUT  /api/firmy/:id — обновление обоих полей;
   • GET  /api/firmy — отдаёт новые поля (firms.list — f.*);
   • firms.withContracts (транспортные операции) — список колонок
     дополнен gorod и cena_perevozki;
   • Вставка фирм из буфера: при дубликате (по ИНН) gorod и
     cena_perevozki НЕ затираются — сохраняются прежние значения.

ЗАЧЕМ
-----
Подготовка следующего шага: учёт стоимости перевозки партии деталей
при выборе лучшего КП — разница между «Лучшими предложениями» разных
фирм может не перекрывать разницу стоимости перевозки. Цена перевозки
задаётся по фирме, дальше будет учитываться в расчёте выбора.
