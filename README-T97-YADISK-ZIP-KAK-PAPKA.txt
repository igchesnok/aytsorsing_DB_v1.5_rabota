T97 — ЯНДЕКС.ДИСК: ZIP-АРХИВ, КОТОРЫЙ НЕ СКАЧИВАЕТСЯ ЦЕЛИКОМ,
ОТКРЫВАЕТСЯ КАК ПАПКА И ПРОВЕРЯЕТСЯ ПО ФАЙЛАМ ВНУТРИ
Кнопка «🔗 Проверить загрузку» (btnCheckUrl), страница «Запросы на КП»
=====================================================================

СИМПТОМ
-------
Проверка ссылки выдавала «HTTP 500 — file IO failure: no more reliable
hosts» на zip-архиве. Та же ошибка и в веб-интерфейсе Яндекса: скачать
архив целиком нельзя, НО он открывается для просмотра, и каждый файл
внутри скачивается по отдельности. Раньше проверка честно сообщала
«не грузится», хотя документация фактически доступна.

РЕШЕНИЕ
-------
Если проба скачивания .zip на Яндекс.Диске не удалась, проверка теперь
открывает архив как папку через docviewer.360.yandex.ru (именно так
работает «просмотр архива» в веб-интерфейсе) и ПРОБНО скачивает каждый
файл внутри (те же Range-пробы с ретраями T92 и бюджетом времени):

  1) GET docviewer.360.yandex.ru/?url=ya-disk-public://<public_key>:<путь архива>
     — сервер выдаёт анонимную сессию (token + dsid прямо в HTML);
  2) POST /api/status          -> fileId (состояние ARCHIVE);
  3) POST /api/archive-listing -> перечень файлов внутри архива;
  4) POST /api/download-url {archivePath: "//"+путь файла} -> ссылка;
  5) Range-GET ссылки -> файл.

Публичный API cloud-api.yandex.net содержимое архива НЕ отдаёт
(DiskNotFoundError по путям внутри zip) — используется именно docviewer.

ОТЧЁТ (UI)
----------
Под строкой архива появляется блок:
  🔓 «Содержимое архива проверено по файлам: внутри N, загружаются M»
  + ✅/❌ строка каждого файла (размер, ошибка, «↻ со 2-й попытки»);
  если доступны ВСЕ файлы — зелёная пометка «вся документация доступна
  по отдельности». В красном блоке «Не прогрузились» у архива — жёлтая
  пометка «🔓 открывается как архив…». Если архив не открывается — 🔒
  с причиной. Сам архив по-прежнему считается «не прогрузившимся»
  (он битый — письмо технологу это отражает), но теперь отчёт точно
  показывает, что документация внутри доступна.

УСТАНОВКА
---------
1. Заменить файлы (пути от корня проекта), перезапустить node
   (правки серверные) и сделать Ctrl+F5.
2. Требуется версия проекта v1.5 (включая T89–T92 — проверка ссылки).
