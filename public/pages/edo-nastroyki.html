⚙️ Настройки ЭДО — портал АВТОВАЗ

Файл настроек: config/edo.json. Сохранённые значения применяются сразу, без перезапуска программы — файл читается при каждом создании служебной записки. Пустое значение поля шаблона/подписанта/темы = встроенное значение по умолчанию.

Подключение к порталу
Темы служебных записок (краткое содержание, krat_sod)
Блок "tema" файла config/edo.json. Подставляемые значения вставляются кнопками-токенами; в момент создания СЗ на портале заменяются реальными данными.
{дата}— дата отгрузки (ДД.ММ.ГГГГ) {отправитель}— фирма-отправитель {получатель}— фирма-получатель {дата}— дата отгрузки (ДД.ММ.ГГГГ) {отправитель}— фирма-отправитель {получатель}— фирма-получатель {номер}— номер запроса ТКП {дата}— дата запроса {фирмы}— фирмы лучших КП
Шаблоны СЗ на портале (идентификаторы шаблонов, d_kod)
Блок "shablon" файла config/edo.json.
Присвоение номера СЗ в СБ об отгрузке (блок "sz_nomer")
Как портал присваивает номер при создании СЗ в СБ об отгрузке: otlozh — отложенное присвоение (rd=2, ch_otl=2; номер появится после регистрации документа на портале), avto — автосоздание (rd=1, ch_otl=1; номер присваивается сразу). Пусто = «otlozh».
Подписывающие (карточка документа на портале)
Блок "podpisant" файла config/edo.json — значения подменяют данные карточки при создании СЗ (как в VBA setDefaults). Пустое значение = встроенный дефолт.
