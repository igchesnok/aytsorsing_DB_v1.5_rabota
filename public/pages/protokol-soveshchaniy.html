План/факт начала подставляются автоматически: по умолчанию — дата получения партии, план-окончание операции переносится в начала следующей (правьте при необходимости). Заполнение фактической даты окончания подтверждает выполнение операции (строка зеленеет). Закрытие факта по последней операции шага с полным выполненным количеством делает партию готовой к отправке (частично выполненная — 50 из 100 — остаётся в работе, пока не доделана) — следующий шаг маршрута откроется на странице «План перевозок». Комментарий по операции сохраняется в fakt_marshruta.kommentariy.
