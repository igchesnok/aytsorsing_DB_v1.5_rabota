T96 — ФИКС «ЗАТОРМАЖИВАНИЯ» ИНФО-ПАНЕЛИ «ИНФОРМАЦИЯ О ДЕТАЛИ»
Страница «Формирование плана производства» (plan.html)
============================================================

СИМПТОМ
-------
В виртуальной таблице «план производства» при ПЕРВОМ клике по записи
(когда выделения ещё нет) панель формы заполняется корректно. Но если
запись уже выделена и пользователь кликает по ДРУГОЙ записи, в блоке
«Информация о детали» поля «№ чертежа» (infoNomerChertezha) и
«Наименование» (infoNaimenovanie) показывают данные ПРЕДЫДУЩЕЙ
выделенной записи («эффект затормаживания»).

ПРИЧИНА
-------
Комбобокс «Деталь (оснастка)» (pOsnastka) — VirtualSelect. При клике по
строке плана fillFromRow программно выставляет значение через
setValue(): внутреннее значение обновляется СИНХРОННО, а данные
выбранной детали в dataset input (nomer_chertezha, osn_naimenovanie) —
ТОЛЬКО АСИНХРОННО, после ответа API (_loadValue). Старые dataProps при
этом не очищались, поэтому в момент вызова updateOsnastkaInfo() быстрый
путь («показать из dataset») проходил проверку getValue() === osnId и
показывал данные ПРОШЛОЙ записи. При первом клике dataset пуст —
срабатывал корректный API-fallback, поэтому баг проявлялся только при
смене выделения.

РЕШЕНИЕ
-------
1) js/common/virtual-select.js (корневая причина):
   - setValue(): dataProps предыдущего выбора удаляются из dataset
     СРАЗУ, синхронно; отменяется ещё идущий _loadValue;
   - _loadValue(): токен _loadValueToken — ответ устаревшего запроса
     (значение снова изменили, пока запрос летел) не применяется;
   - _selectItem(): явный выбор пользователя отменяет идущий _loadValue;
   - clear(): очищаются и dataProps.
2) js/configs/plan.config.js: в dataProps pOsnastka добавлен ds_id: 'id'
   (id детали попадает в dataset).
3) js/app-plan.js: быстрый путь updateOsnastkaInfo() теперь доверяет
   dataset ТОЛЬКО при совпадении ds_id с запрошенным id; иначе —
   корректный API-fallback (уже защищён токеном от гонок).

СОСТАВ АРХИВА
-------------
js/common/virtual-select.js   — общий виртуальный селект (правки setValue/_loadValue/_selectItem/clear)
js/configs/plan.config.js     — конфиг страницы «План производства» (dataProps + ds_id)
js/app-plan.js                — модуль страницы (условие быстрого пути в updateOsnastkaInfo)
