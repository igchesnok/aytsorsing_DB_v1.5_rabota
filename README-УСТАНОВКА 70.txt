УСТАНОВКА ОБНОВЛЕНИЯ t70 — «Формирование плана производства»: порядок колонок + виртуальные «№ запроса» и «№ зак. по дог.»
======================================================================================================

ЧТО СДЕЛАНО
-----------
Страница «Формирование плана производства» (таблица позиций годового плана):

1. Колонки «№ чертежа» и «Наименование» перенесены сразу после колонки
   «Фирма» (раньше были последними).

2. Колонка «№ зак.» переименована в «№ зак. ПТО» — так же, как называется
   поле в форме («№ заказа ПТО»).

3. После колонки «№ зак. ПТО» добавлены две ВИРТУАЛЬНЫЕ колонки (значения
   вычисляются на сервере из связанных таблиц, в базе не хранятся):

   «№ запроса» — номер запроса КП, по которому у позиции выбрано лучшее КП
   (план -> КП -> запрос КП). Если у позиции нет КП — пусто.

   «№ зак. по дог.» — номер и дата заказа по договору, в котором состоит
   позиция плана. Формат: «<№> от <дата>», например «ЗД-2026-001 от 14.10.2026».
   Если позиция ещё не добавлена в заказ — пусто.

Новая структура таблицы:
  Год | Фирма | № чертежа | Наименование | № зак. ПТО | № запроса |
  № зак. по дог. | План кол-во | План. срок изгот. | Статус позиции

Дополнительно: у «№ запроса» и «№ зак. по дог.» при наведении всплывает
полное значение (тултип), ширина колонок изменяется мышью как у остальных.
Позиции без КП и без заказа не пропадают из таблицы (добавлены через LEFT
JOIN / подзапрос — строки не дублируются).

СОСТАВ АРХИВА
-------------
  src/routes/helpers/syntheticTables.js — сервер: список позиций плана
        (/api/plan и /api/plan/detail): поля zapros_nomer, zak_po_dog
  public/js/configs/plan.config.js      — конфиг страницы: порядок колонок,
        переименование, 2 новые виртуальные колонки
  README-УСТАНОВКА.txt                  — этот файл

КАК УСТАНОВИТЬ
--------------
1. Остановить сервер (окно с node server.js — Ctrl+C).
2. Скопировать 2 файла из архива в папку проекта С ЗАМЕНОЙ:
     src/routes/helpers/syntheticTables.js
     public/js/configs/plan.config.js
3. Запустить сервер заново (node server.js, порт 3110).
   ВАЖНО: в этом обновлении серверный файл — перезапуск обязателен.
4. Открыть страницу «Формирование плана производства» и нажать Ctrl+F5
   (обновление со сбросом кэша).

ПРОВЕРКА ПОСЛЕ УСТАНОВКИ
------------------------
1. Порядок колонок: Год, Фирма, № чертежа, Наименование, № зак. ПТО,
   № запроса, № зак. по дог., План кол-во, План. срок изгот., Статус позиции.
2. У позиций, добавленных в заказ по договору, «№ зак. по дог.» показывает
   номер и дату заказа («… от …»).
3. У позиций с выбранным КП заполнен «№ запроса».
4. Фильтры (№ чертежа, Наименование, Фирма и др.) работают как раньше.

Если что-то не так — верните резервные копии двух файлов.
