ЧТО НОВОГО (4 улучшения)
------------------------
1. SCATTER ПЕРЕКЛЮЧАЕТСЯ КЛИКОМ ПО СТРОКАМ МАТРИЦЫ ВЫБОРА:
   • клик по строке позиции — диаграмма пересчитывается ПОД ЭТУ
     ПОЗИЦИЮ (X — трудоёмкость партии позиции, Y — стоимость
     партии, ◆ Цель — целевые параметры позиции);
   • клик по строке ИТОГО — итоги по всем позициям (как раньше);
   • активная строка матрицы подсвечивается синей полосой;
   • дубль переключения — селект «Итоги по всем позициям / …»
     в тулбаре диаграммы (синхронизирован в обе стороны);
   • клик по ячейке фирмы по-прежнему открывает карточку КП,
     по ячейке ИТОГО — выбирает фирму (прежнее поведение).

2. ЧЕКБОКС «НЕ ДОПУСКАЕТСЯ РАЗБИВАТЬ ПАРТИЮ» (в тулбаре диаграммы,
   по умолчанию включён, состояние — в localStorage):
   • включён — партия заказывается у одной фирмы, сборной точки нет;
   • СНЯТ — на диаграмме появляется СБОРНАЯ ТОЧКА (⭑ зелёная
     звезда): по каждой позиции берутся ЛУЧШАЯ стоимость и ЛУЧШАЯ
     трудоёмкость (могут быть от разных фирм) и складываются —
     теоретический минимум при разбиении партии между фирмами;
     тултип звезды показывает состав по позициям (какая фирма дала
     цену, какая — трудоёмкость). Если по позиции минимум труда и
     минимум цены у одной и той же фирмы и точка совпадает с точкой
     фирмы — сборная не рисуется (нет дублирования).

3. КОНТЕЙНЕР ПРИНЯТИЯ РЕШЕНИЯ: матрица выбора + диаграмма теперь
   в отдельном блоке со сворачиванием КАК У БЛОКА ФИЛЬТРОВ (t73):
   шапка «Принятие решения» + кнопка-треугольник ▲/▼ справа;
   контент скрывается целиком, шапка остаётся; состояние — в
   localStorage (offers_decision_collapsed), переживает F5;
   при сворачивании ресайзер прячется. Блок показывается только
   когда есть данные (запрос без КП — скрыт вместе с матрицей).

4. ГОРИЗОНТАЛЬНЫЙ РЕСАЙЗЕР между контейнером принятия решения и
   сводной таблицей КП (штатный .resizer.horizontal — тянется
   мышью, меняет высоту контейнера; работает в конструкции
   .panel.gorizont с flex-direction: column).

5. ВЕРТИКАЛЬНЫЙ СКРОЛЛБАР СТРАНИЦЫ: раньше body был overflow:hidden
   (всё внутри 100vh) — с матрицей, диаграммой и шагами согласования
   блоки перекрывались или схлопывались до нулевой высоты. Теперь
   страница прокручивается (body overflow-y:auto), таблицам деталей
   и сводной заданы опорные высоты (34/36vh) — виртуальные таблицы
   рендерятся корректно, ничего не схлопывается.

УСТАНОВКА
---------
1. Файлы клиентские — останавливать сервер не нужно.
2. Скопируйте 2 файла из архива в папку проекта ПОВЕРХ существующих.
3. В браузере: Ctrl+F5 (кэш модулей!).
4. Откройте «Внесение коммерческих предложений», выберите запрос КП
   с предложениями: под сводной таблицей — блок «Принятие решения»
   (матрица + диаграмма). Кликайте по строкам матрицы — диаграмма
   переключается; снимите чекбокс «не допускается разбивать партию» —
   появится зелёная звезда сборной.
