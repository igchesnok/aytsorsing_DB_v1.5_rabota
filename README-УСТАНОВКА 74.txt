 T74 — «МАТРИЦА ВЫБОРА ПОСТАВЩИКА» (визуализация сводной КП)

ЧТО ДЕЛАЕТ
----------
Под сводной таблицей КП появляется блок «Матрица выбора поставщика» —
с одной картинки видно, чьё предложение лучше:

  • СТРОКИ  — позиции (детали ПТО) запроса: № чертежа, наименование,
    кол-во шт;
  • КОЛОНКИ — ТОЛЬКО фирмы, давшие хотя бы одно предложение с ценой
    (фирмы без предложений в графике не отображаются);
  • ЯЧЕЙКА  — стоимость партии (Стоим × Кол-во, руб. без НДС) на
    зелёно-красной шкале ПО СТРОКЕ (зелёный — дешевле, красный —
    дороже) + трудоёмкость ед. (н/ч) + тип производства (сокращённо:
    ПЦ = полный цикл, ПМ б/ТО = полная мех. обработка без ТО,
    ЧМ с ТО / ЧМ б/ТО = частичная мех. обработка с/без ТО);
  • ★ в строке — МИНИМАЛЬНАЯ стоимость (тот же критерий, что
    «лучшее предложение по цене»);
  • строка ИТОГО — сумма по позициям с КП + мини-бары + покрытие
    «N из M поз.». ★ ИТОГО получает фирма с минимальной суммой СРЕДИ
    ФИРМ С МАКСИМАЛЬНЫМ ПОКРЫТИЕМ позиций (фирма, давшая цену на одну
    позицию из шести, не может быть «лучшей» по сумме — её бар серый);
  • слева справочная колонка «Целевая ПТО» (труд-ть × целевая цена
    н/ч × план кол-во) — для оценки отклонения;
  • НАВЕДЕНИЕ на ячейку — тултип с полными параметрами КП:
    стоимость партии/ед., трудоёмкость, цена н/ч, кол-во (фирма/план),
    срок, отклонение от целевой (₽ и %), обоснование;
  • КЛИК по ячейке — карточка КП (все параметры + договор) с кнопкой
    «Выбрать фирму в фильтре» (группа фирмы центрируется в сводной);
  • КЛИК по ИТОГО фирмы — выбрать фирму в фильтре.

Матрица обновляется ВМЕСТЕ со сводной таблицей (те же данные, без
запросов к серверу): смена запроса, фильтр «Без КП», сохранение КП,
импорт из Excel — всё отражается сразу. Нет данных/нет предложений —
блок скрывается сам.

УСТАНОВКА
---------
1. Остановите сервер НЕ обязательно (файлы клиентские), но если
   принято — перезапустите как обычно.
2. Скопируйте 3 файла из архива в папку проекта ПОВЕРХ существующих
   (public/js/modules/offers-matrix.js — новый файл, просто положите).
3. В браузере: Ctrl+F5 (кэш модулей!).
4. Откройте «Внесение коммерческих предложений», выберите запрос КП
   с предложениями — под сводной таблицей появится матрица.

ТРЕБОВАНИЯ
----------
Актуальный проект (v59 + t60..t73). Внешних библиотек НЕ требует
(чистый HTML/CSS/JS). Данные — таблица kp БД firmy.db (читаются,
НЕ изменяются).

ПРОВЕРЕНО
---------
Тест на образце «заявка №4» (6 позиций × 11 фирм, 7 с КП):
88 проверок OK — состав колонок (фирмы без КП скрыты), ★ = min по
строке, ИТОГО = суммы колонок (сверка с API), целевая колонка,
тултип, карточка, выбор фирмы, скрытие при запросе без цен,
консоль без ошибок. Регрессия t63b-смок и t73 — без новых ошибок.
