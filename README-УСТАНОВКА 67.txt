УСТАНОВКА ОБНОВЛЕНИЯ t67 — «План производства»: фирма лучшего КП второй колонкой, «№ зак.» с тултипом
======================================================================================================

ЧТО ДЕЛАЕТ ОБНОВЛЕНИЕ
---------------------
Страница «Формирование плана производства» (plan.html) — те же доработки, что ранее
сделаны для «Графика изготовления» (t66):

1. Колонка «Фирма» перенесена на 2-е место (сразу после «Год»).
   Это фирма лучшего КП позиции плана (план -> КП -> фирма) — тот же механизм,
   что в отчёте «Плоская таблица» и в «Графике изготовления».
   У позиций без назначенного КП колонка пустая (строки не пропадают).

2. Добавлена колонка «№ зак.» (3-я) — это № заказа ПТО (поле «№ заказа ПТО»
   из формы позиции плана; в «Графике изготовления» колонка «№ Зак.» — то же поле).
   При наведении на ячейку «№ зак.» всплывает ПОЛНОЕ значение (значения длиннее
   колонки обрезаются — тултип показывает целиком).

3. У колонки «Фирма» (и «№ зак.») при наведении тоже видно полное значение.

4. Колонка «Фирма» ресайзится перетаскиванием края заголовка — как все колонки
   таблицы (механизм ресайза виртуальной таблицы уже был, новая колонка его
   наследует автоматически; проверено: 150 -> 230 px и обратно).

ВАЖНО
-----
* Колонка «Фирма» заполняется из КП позиции плана. Если КП ещё не выбран
  (на странице «Запросы на коммерческие предложения»), ячейка пустая — это штатно.
* Тултипы добавлены только там, где включены (Фирма, № зак.); остальные страницы
  не изменились.

СОСТАВ АРХИВА
-------------
  public/js/configs/plan.config.js   — порядок колонок таблицы плана,
                                       «№ зак.» в таблице, включенные тултипы
  public/js/common/virtual-table.js  — общая опция колонки tooltip (тултип ячейки)
  public/js/common/crud-module.js    — передача опции tooltip из конфига в таблицу
  README-УСТАНОВКА.txt               — этот файл

КАК УСТАНОВИТЬ
--------------
1. Остановить сервер (окно с node server.js — Ctrl+C).
2. Скопировать 3 файла из архива в папку проекта С ЗАМЕНОЙ:
     public/js/configs/plan.config.js
     public/js/common/virtual-table.js
     public/js/common/crud-module.js
3. Запустить сервер заново (node server.js, порт 3110).
4. В браузере открыть страницу «Формирование плана производства»
   и нажать Ctrl+F5 (обновление с сбросом кэша), чтобы загрузились новые файлы.

ПРОВЕРКА ПОСЛЕ УСТАНОВКИ
------------------------
* Вторая колонка таблицы — «Фирма», третья — «№ зак.».
* Наведите курсор на ячейку «№ зак.» — всплывает полный номер заказа.
* Потяните край заголовка «Фирма» — ширина меняется, как у остальных колонок.

Если что-то не так — верните резервные копии трёх файлов.
