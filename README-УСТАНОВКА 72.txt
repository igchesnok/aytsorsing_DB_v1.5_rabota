T72 — «Формирование плана производства»: сворачиваемые фильтры + фильтр «№ запроса»
====================================================================================

ЧТО СДЕЛАНО
-----------

1. Блок фильтров (.filter-section) стал сворачиваемым.
   В правом верхнем углу блока — маленькая кнопка-треугольник:
   ▲ — свернуть (остаётся узкая полоса с кнопкой), ▼ — развернуть.
   Состояние запоминается (localStorage) и переживает перезагрузку
   страницы. Значения фильтров при сворачивании/разворачивании
   НЕ сбрасываются, таблица и её фильтрация продолжают работать.

2. Новый фильтр «№ запроса» (строка в левой колонке фильтров, после «Фирмы»).
   Ищет позиции плана, включённые в запрос КП, номер которого содержит
   введённый текст (поиск частичный, без учёта регистра, с поддержкой
   «Кир→Лат» — букв-двойников, как у остальных текстовых фильтров).
   Рядом кнопка очистки «×». Фильтр комбинируется с остальными фильтрами.
   Источник данных — та же связь, что у колонки «№ запроса» (t71):
   kp.id_plana -> zapros_kp.n_zaprosa.

ФАЙЛЫ В АРХИВЕ
--------------

  src/routes/planRoutes.js                  — серверный (белый список GET-параметров)
  src/routes/helpers/syntheticTables.js     — серверный (условие фильтра)
  public/pages/plan.html                    — клиентский (кнопка, строка фильтра, стили)
  public/js/app-plan.js                     — клиентский (логика сворачивания)
  public/js/configs/plan.config.js          — клиентский (поле фильтра + кнопка очистки)

УСТАНОВКА
---------

1. Скопировать все 5 файлов поверх файлов проекта с сохранением путей.
2. ПЕРЕЗАПУСТИТЬ СЕРВЕР (обязательно: 2 серверных файла).
3. В браузере обновить страницу плана с очисткой кэша (Ctrl+F5).

ПРОВЕРКА
--------

- Клик по треугольнику в правом верхнем углу блока фильтров:
  ▲ сворачивает блок, ▼ разворачивает; после F5 состояние сохраняется.
- Ввести в фильтр «№ запроса» номер (целиком или часть, в любом
  регистре) — в таблице остаются только позиции этого запроса.
- Кнопка «×» рядом с фильтром очищает его; «Сбросить все» — все.

ТРЕБОВАНИЯ
----------

Актуальный проект v59 + t60..t71. Все 5 файлов целиком заменяют
предыдущие версии (учитывают правки t60..t71).
